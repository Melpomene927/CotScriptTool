# CotScriptTool

Course of Temptation 的 **CotScriptTool** ModLoader 模組。本倉庫**僅提供 Releases 下載**，不含原始碼或建置腳本。

## 安裝

1. 請先安裝 **ModLoader**（建議 **^2.17.0** 或與 Release 說明一致之版本）。
2. 開啟本倉庫 **[Releases](https://github.com/Melpomene927/CotScriptTool/releases)**，下載對應版本的 `CotScriptTool-{version}.mod.zip`。
3. 依 ModLoader 說明將 `.mod.zip` 放入遊戲 Mod 目錄，於 ModLoader 中啟用 **CotScriptTool**。
4. 重新載入或啟動遊戲。

各版本變更與依賴請見該 Release 附註。
